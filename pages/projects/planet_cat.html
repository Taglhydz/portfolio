Planet Cat

Voir sur GitHub

Planet Cat est un site web développé uniquement en React dans le cadre de ma formation au CESI. Ce projet d'apprentissage m'a permis de découvrir et de maîtriser les concepts fondamentaux du framework React, notamment les composants, les hooks, et la gestion d'état.

Le site présente un thème ludique autour des chats, tout en mettant en pratique les bonnes pratiques de développement en React et la création d'une application web moderne et interactive.
