JDM Pulse

Voir sur GitHub

JDM Pulse est un site web conçu pour les passionnés de voitures japonaises (JDM - Japanese Domestic Market). Cette plateforme permet aux utilisateurs de découvrir les modèles iconiques, consulter leurs spécifications détaillées et sauvegarder leurs véhicules préférés en favoris.

Le site offre une expérience immersive avec une interface moderne et responsive, permettant aux utilisateurs de parcourir facilement la collection de véhicules JDM légendaires.
