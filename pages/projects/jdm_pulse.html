JDM Pulse

Voir sur GitHub Voir le site en ligne

JDM Pulse est un site sur les voitures japonaises (JDM, pour Japanese Domestic Market). On peut y parcourir une liste de modèles connus, voir leurs caractéristiques et mettre ses préférés en favoris.

Le front est fait en React, l'API en Laravel et les données sont stockées dans une base MySQL. Le site est en ligne, vous pouvez le tester avec le lien au-dessus.
