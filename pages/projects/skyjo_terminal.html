Skyjo sur un terminal

Voir sur GitHub

Skyjo Terminal est une adaptation du célèbre jeu de cartes Skyjo, développée en Python pour être jouée directement dans un terminal. Cette version console permet de jouer de 2 à 8 joueurs et reproduit fidèlement les règles du jeu original.

Le projet met l'accent sur une interface utilisateur claire et intuitive malgré les contraintes du terminal, offrant une expérience de jeu fluide et agréable.
